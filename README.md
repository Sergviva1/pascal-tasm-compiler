# Анализатор Pascal

Учебный проект по системному ПО, вариант № 10. Наша часть компилятора — синтаксический и семантический анализатор: он получает токены от лексера, строит дерево программы и сообщает об ошибках.

Сейчас готовимся к ЛР № 1: объявления переменных и простые присваивания. [План работ](PLAN.md) · [Интерфейсы компонентов](docs/interfaces.md).
