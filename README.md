# Компилятор Pascal для Intel 8086

Цель проекта — перевод подмножества Pascal в ассемблер TASM для DOS. На этапе ЛР № 1 лексер выделяет токены, парсер разбирает объявления и простые присваивания, а генератор пишет инструкции Intel 8086 из AST v1. Парсер проверяет форму объявлений и находит дубликаты; разрешение имён в операторах и проверка типов выражений относятся к ЛР № 2.

| Каталог | Назначение |
|---|---|
| `lexer/` | Лексер, утилита `lexer_cli` и примеры программ |
| `parser/` | Парсер ЛР № 1, утилита `parser_cli` и автономные тесты |
| `codegen/` | Генератор ассемблера и пример его вызова |
| `shared/` | Общие типы токенов и узлов дерева |
| `docs/` | РБНФ варианта, границы этапов и контракты обмена |

`lexer_cli` печатает токены файла `.pas`. `parser_cli` принимает `.pas` и печатает AST и таблицу символов (см. [парсер ЛР № 1](parser/README.md)). `codegen_demo` записывает `.asm` из демонстрационного дерева. Сквозного запуска до генерации ASM ещё нет.

**Сборка и проверка** (C++17, CMake 3.16+):

```sh
cmake -S . -B build
cmake --build build
(cd build && ctest --output-on-failure)
```

Для сборки компонентов и запуска тестов DOSBox и TASM не нужны.
