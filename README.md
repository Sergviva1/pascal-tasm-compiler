# Компилятор Pascal для Intel 8086

Проект переводит подмножество Pascal в ассемблер TASM для DOS. Лексер читает исходный текст и выделяет токены. Парсер строит дерево программы и проверяет имена и типы. Генератор обходит дерево и записывает инструкции Intel 8086 в `.asm`.

| Каталог | Назначение |
|---|---|
| `lexer/` | Лексер, утилита `lexer_cli` и примеры программ |
| `parser/` | Парсер и семантический анализатор (в разработке) |
| `codegen/` | Генератор ассемблера и пример его вызова |
| `shared/` | Общие типы токенов и узлов дерева |

Пока лексер и генератор запускаются независимо: `lexer_cli` принимает путь к `.pas`, а `codegen_demo` — путь для записи `.asm` из демонстрационного дерева. Сквозного запуска компилятора ещё нет.

**Сборка и проверка** (C++17, CMake 3.16+):

```sh
cmake -S . -B build
cmake --build build
(cd build && ctest --output-on-failure)
```

Для сборки компонентов и запуска тестов DOSBox и TASM не нужны.
