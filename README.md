# Компилятор Pascal для Intel 8086

Командный учебный проект на C++: разрабатываем компилятор подмножества Pascal для DOS. Лексер разбивает исходный текст на токены, синтаксический и семантический анализатор строит дерево программы и проверяет имена и типы, а генератор переводит дерево в ассемблер для TASM.

**Вариант № 10:** процедуры, `if`, сравнения, передача данных по указателю и именованные константы. Первая лабораторная посвящена объявлениям целых переменных и простым присваиваниям.
