# Лексическая грамматика (базовое подмножество Pascal)

Ниже приведена грамматика для учебного подмножества Pascal. Точный состав
зарезервированных слов и дополнительных конструкций должен уточняться
после получения индивидуального варианта.

## 1. Базовые лексические правила

```ebnf
letter          = "A"…"Z" | "a"…"z" ;
digit           = "0"…"9" ;
identifier      = (letter | "_"), { letter | digit | "_" } ;
decimal_integer = digit, { digit } ;
assign          = ":=" ;
```

## 2. Зарезервированные слова

`program`, `var`, `begin`, `end`, `integer`, `real`, `boolean`, `char`,
`string`, `const`, `type`, `procedure`, `function`, `if`, `then`, `else`,
`while`, `do`, `for`, `to`, `downto`, `repeat`, `until`, `array`, `of`,
`record`, `not`, `and`, `or`.

Ключевые слова не чувствительны к регистру. Идентификаторы сохраняют
исходное написание.

## 3. Операторы и разделители

Операторы: `:=`, `+`, `-`, `*`, `/`, `=`, `<>`, `<`, `<=`, `>`, `>=`.

Разделители: `;`, `:`, `,`, `.`, `(`, `)`.

Пробельные символы: пробел, табуляция, перевод строки и возврат каретки;
они разделяют лексемы и сами токенами не являются.

## 4. Дополнительные формы полной грамматики

Строковый литерал (описание): `'`, { любой символ, кроме `'` либо удвоенная
кавычка `''` }, `'`.

Комментарий (описание): `{`, { любой символ, кроме `}` }, `}` либо
`(*`, { любые символы до `*)` }, `*)` либо `//`, { символы до конца строки }.

Эти дополнительные формы включены в описание возможного лексического
языка, но не реализованы в текущей версии программы.

## 5. Категории токенов

- PROGRAM, VAR, BEGIN, END;
- INTEGER_TYPE, REAL_TYPE, BOOLEAN_TYPE, CHAR_TYPE, STRING_TYPE;
- прочие зарезервированные слова;
- IDENTIFIER;
- DECIMAL_INTEGER;
- ASSIGN;
- COLON, SEMICOLON, COMMA, DOT, LEFT_PAREN, RIGHT_PAREN;
- PLUS, MINUS, STAR, SLASH, EQUAL, NOT_EQUAL, LESS, LESS_EQUAL,
  GREATER, GREATER_EQUAL;
- STRING_LITERAL, COMMENT (описаны, но пока не реализованы);
- EOF.

## 6. Что реализовано в ЛР № 1

Реализованы чтение исходного файла, пропуск пробельных символов,
идентификаторы, зарезервированные слова, десятичные целые числа,
оператор присваивания `:=`, основные разделители, позиции токенов,
собственное динамическое хранилище и диагностика недопустимого символа.

Строковые литералы и комментарии пока только описаны. Их реализация
может быть добавлена на следующих этапах в соответствии с вариантом.
