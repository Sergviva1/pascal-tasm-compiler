# ЛР № 1: ожидаемые результаты T1–T4

`.pas` — читаемое представление тестовых входов. Автономный тест в [`tests.cpp`](tests.cpp) вручную заполняет `TokenStorage` соответствующими токенами, включая позиции и `END_OF_FILE`, и не зависит от лексера. Ниже — ожидания; точные текстовые эталоны лежат в [`expected/`](expected/), фактический вывод — отдельно в [`parser/results/lab1/`](../../results/lab1/).

## T1 — присваивание числа

Вход: [T1.pas](T1.pas). Разбор успешен. Ожидаемое дерево (представление `Program` v1):

```text
Program
  VarDeclaration: x : integer
  Block
    Assignment
      Target: x
      IntegerLiteral: 10
```

Таблица символов: `x`, переменная, `integer`, глобальная область, объявление `2:5`.

## T2 — список имён и присваивание из переменной

Вход: [T2.pas](T2.pas). Разбор успешен. Порядок объявлений и операторов сохранён, имена нормализованы.

```text
Program
  VarDeclaration: x : integer
  VarDeclaration: y : integer
  Block
    Assignment
      Target: x
      IntegerLiteral: 10
    Assignment
      Target: y
      Variable: x
```

Таблица символов: `x`, переменная, `integer`, глобальная область, `2:5`; `y`, переменная, `integer`, глобальная область, `2:8`.

## T3 — повторное объявление

Вход: [T3.pas](T3.pas). `x` и `X` — одно имя. Ошибка на втором объявлении; AST и таблица не выдаются.

```text
3:5: повторное объявление 'X' (первое объявление: 2:5)
```

## T4 — отсутствует двоеточие

Вход: [T4.pas](T4.pas). Синтаксическая ошибка на `integer`, полученном вместо `:`; AST и таблица не выдаются.

```text
2:7: ожидалось ':', получено 'integer'
```
